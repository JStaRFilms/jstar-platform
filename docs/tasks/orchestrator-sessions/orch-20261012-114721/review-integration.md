# Review portfolio integration
## Objective
Find confirmed requirement violations and regressions in the integration, not style preferences or speculative enhancements.
## Scope
Read-only inspection of the final coder diff and focused test receipts against the original brief and baseline.
## Required capabilities
None. Read-only.
## Definition of done
Check typed playback variants, all thirteen real records, compliant iframe layout, original hero preservation, persistent sample DOM/state, filters/order/focus/windowing, source lifecycle and forbidden external effects. Identify only concrete blocking issues with file/line and reproduction.
## Deliverables
Focused review report, severity and any remaining verification limitations. No edits.
